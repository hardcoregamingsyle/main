# Girl Flapper

A Flappy Bird-style game where you control a cute girl character through pink pipe obstacles.

## Features

- **Cute Character**: Play as a stylized girl with hair, face, and dress
- **Responsive Controls**: Use Spacebar or click/tap to make the girl fly
- **Score Tracking**: Track your current score and high score (saved locally)
- **Smooth Gameplay**: 60 FPS animation with smooth physics
- **Visual Feedback**: Colorful gradients and clear UI elements

## How to Play

1. Click "Start Game" to begin
2. Press **SPACE** or **CLICK/TAP** to make the girl fly upward
3. Avoid the pink pipes
4. Pass through pipes to gain points
5. Don't hit the ground or the pipes!

## Installation

```bash
npm install
```

## Running the Game

```bash
npm start
```

This will start a local server on port 3000 at http://localhost:3000
